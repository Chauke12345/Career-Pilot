# Career Pilot AI

AI-powered career assistant built with Django and Groq AI.

## Features

🤖 AI Career Assistant
- Career advice
- Interview preparation
- Job search guidance

📄 Resume Analyzer
- Upload CV
- ATS scoring
- Skills analysis
- Improvement recommendations

🎯 Resume Job Matching
- Compare CV against job descriptions
- Identify matching skills
- Find skill gaps

📊 Job Application Tracker
- Track applications
- Monitor interview progress
- Manage job search pipeline

## Tech Stack

Backend:
- Python
- Django
- Django REST Framework

Frontend:
- HTML
- CSS
- JavaScript

Database:
- PostgreSQL

AI:
- Groq API
- Llama models

Authentication:
- JWT

## Installation

Clone repository:

git clone https://github.com/Chauke12345/Career-Pilot.git

Navigate:

cd backend

Install requirements:

pip install -r requirements.txt

Run migrations:

python manage.py migrate

Start server:

python manage.py runserver
